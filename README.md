# พักตับ ยืดชีวิต — แบบสอบถาม A13 + Dashboard

หน้าเว็บ (GitHub Pages) สำหรับโครงการ “พักตับ ยืดชีวิต” — ข้อมูลเก็บใน Google Sheet ผ่าน Google Apps Script

| หน้า | ใช้โดย |
|---|---|
| `index.html` | ทุกคน — หน้าแรก สถิติภาพรวม (อ่านอย่างเดียว) + ปุ่ม LOGIN |
| `form.html` (`?area=รหัส`) | ประชาชน — ตอบแบบสอบถาม (`index.html?area=` จะพาไปหน้านี้อัตโนมัติ) |
| `login.html` | เจ้าหน้าที่ — เข้าสู่ระบบ |
| `dashboard.html` | เจ้าหน้าที่ — ติดตามงาน / รายงานสถิติ / ประมวลผลตามตัวแปร |
| `qr.html` | เจ้าหน้าที่ — พิมพ์ QR รายพื้นที่ |

ตั้งค่า: แก้ `js/config.js` ใส่ URL เว็บแอป Apps Script

ไฟล์นี้ไม่มีข้อมูลผู้ตอบหรือรหัสผ่าน — ทั้งหมดอยู่ใน Google Sheet ของโครงการ
